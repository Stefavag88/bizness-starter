# Prompt-driven starter workflows

The owner approved creation and maintenance skills, portable project guidance and a configuration map, followed by creation of PPConsulting using those workflows. Implement inline with one final independent review; ordinary prompt changes use one implementer and relevant checks, not automatic agent teams.

The source-only starter-create-site skill guides verified initializer dry-run then actual generation, frozen install/check/test/build/Worker dry-run and local startup. Preserve independent client boundaries, inert infrastructure defaults, explicit target selection and original sources. Never clone/copy a legacy application's backend to simulate initialization.

Every generated app receives concise AGENTS.md from a client-specific template, starter-maintain-site under .agents/skills, and docs/CONFIGURATION_MAP.md. The source starter's historical AGENTS.md must not leak as the client's guidance. Reusable guidance maps user intent to canonical Settings/Pages/editorial/project/theme ownership, protects immutable IDs/URLs and original ASTs, prohibits generated edits, and extends registered shared contracts only when existing settings cannot express the request. Deployment/secrets/sending remain separately authorized and blocked by current gates.

A read-only pnpm site:inspect command reads canonical project/content and reports actual project/profile/module choices, page/section identities, visibility/surface/variant choices and ownership paths. It must work in independent clients without source preset/initializer imports and without configure, writes, secrets or runtime side effects. Guidance treats schemas/current inspection as authoritative; docs are a map, not an invented configuration API.

Creation guidance remains source-only. Maintenance guidance, map and inspection runtime dependencies join both explicit runtime inventories. The initializer fingerprints the client AGENTS template as an overlay input and validates exact destination ownership as before. Frozen release snapshots include the resulting app guidance; no automatic upgrade overwrites independent clients.

Validate skill metadata/references and prompt behavior using baseline/forward read-only assessments; assert generated artifacts and export closure through real initializer tests. Run normal focused/check/full verification with owned launcher stopped and independently initialize PPConsulting through the actual CLI. English Markdown, localized public copy. No hosted resources, credentials, real sending, remote SQL or deployment.
