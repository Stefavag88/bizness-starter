The retained [offline original source](assets/create-starter-samples.py) uses Python's standard-library RGB scanlines, PNG chunks and zlib. Each image has a pale field, ochre circle and green geometric layers; the portrait adds a vertical accent. It is an original-art generator, never a runtime derivative pipeline, build step or package dependency. It creates files exclusively and refuses overwriting existing assets. Exact compressed bytes assume the original Python/zlib toolchain; dimensions and pixel formulas are retained independently.

These PNGs remain in staging/production as legitimate reusable CMS-selectable uploads. Dedicated local showcase JS/CSS remain excluded.
