# Developer domain extensions

Composition C uses static developer registrations. Rooms is the only shipped business extension and is disabled by default. Existing offerings, people and articles retain their named arrays. This recipe describes the accepted interfaces at runtime commit `2c451d0`; whole-branch review approved candidate `7a12969`; final documentation scoped rereview and controller closeout remain pending. See [architecture](ARCHITECTURE.md), [Rooms authoring](ROOMS_AUTHORING.md) and [acceptance evidence](superpowers/plans/2026-10-18-starter-v2-composition-c-evidence.md).

## Registration recipe

1. Implement the domain under `packages/domains/DOMAIN/`. Keep schemas browser-safe and strict. Import `LIMITS` from `packages/content/limits.mjs`, safe prose helpers from `rich-text.mjs` and source syntax from `media.mjs`. Do not import the schema/section aggregators back into their registrations. Filesystem loading and physical image decoding stay server-only.
2. Add an explicit boolean module key/default to `packages/config/project.mjs` and `project.d.mts`. Unknown keys reject. A registry is code, never serialized project configuration or a runtime plugin loader.
3. Augment `DomainRecordMap` and `LocalizedDomainRecordMap` in `packages/content/domain-contracts.ts` from domain-owned `types.ts`. For an index/list also augment `PageTemplateMap` and `SectionCopyMap` in `packages/content/types.ts`. Load augmentations through the type-only imports in the paired `domain-registry.d.mts` and `module-extensions.d.mts` registration seams. Source and localized `domains` are partial mapped array containers.
4. Register a `DomainDefinition<R,L>` in `packages/content/domain-registry.mjs`. `defineDomain` validates/copies/freezes a definition; `createDomainRegistry` rejects duplicate claims. Declare `key`, `collectionName`, flat `directory`, `schema`, `ownedPages`, `enabled(project)`, `richFields`, `projectRecord`, `routePath`, `validate` and `enquiry`. Keys/directories are lowercase static identifiers at most 64 characters; native aliases are GraphQL-safe. Built-in aliases and protected Page identities are reserved. Owned Page declarations explicitly bind `{filename,template,contentId}` before any file parsing. Rooms uses `rooms` / `room` / `rooms`, owning `rooms.json` / `rooms` / `rooms`.
5. For an index/list, register its literal template and section definition in `packages/content/module-extensions.mjs`. Section definitions own `type`, `nativeName`, `copySchema`, `variants`, `referenceFields`, `defaultReference`, `richFields`, `defaultCopy` and `enabled`. Keep disabled schemas registered for dormant copy round-trip; generic guards hide their chooser/public output. Register all native copy controls in `moduleSectionCopyFields` in `tina/fields/section-copy.ts`. Native underscore aliases derive through `NativeSectionName<T>`; field names must remain static under item/record changes.
6. Register `{key,allowCreate,assertIdentity,buildCollection}` in `nativeDomainRegistrations` in `tina/domains/index.ts`. Use the existing collection wrapper/common save hook. `buildDomainCollections(project)` verifies that collection name/path match the content declaration and disables Delete/folders. `getNativeDomainAdapters(project, {registry?,nativeRegistry?})` supplies active schema/rich paths/identity adapters. `assertDomainIdentity(candidate,current,submission)` enforces explicit flat create/update, draft-only creation (including supplied translations), and immutable saved contentId/slug. Existing records are matched by persisted filename; a module wrapper can additionally protect retained nested IDs.
7. Add static Astro components and register detail `{key,renderer}` in `apps/site/src/templates/domains/index.ts`; register any list in `apps/site/src/templates/sections.ts`. No CMS component path is executable. Duplicate renderer registrations reject; `assertDomainRendererCoverage(project)` runs in route `getStaticPaths`, before static generation. Missing native/render coverage fails actionably. Unrelated editorial markup remains in `EditorialDetail.astro`.
8. Add a dormant draft owned index, domain folder and focused tests. Do not publish seed business records, mutate Home/navigation automatically, or add domain-name branches to loader/localizer/catalog/routes/native-save/Worker algorithms. Escalate a missing generic seam before changing those algorithms.

## Projection and consumers

`projectRecord(record, context)` returns `Omit<L,keyof RouteFields> | null`; `routePath(record, context)` returns an absolute canonical locale path. `DomainContext` is `{project,locale,now,pages}` with already localized/published base Pages. Enforce the domain's index dependency and independent localized publication using that clock; do not recursively call `localizeContent`, inherit schedules or fall back to another language. Generic finalization adds path and reciprocal alternatives, checks reserved/colliding paths, and emits `{kind:'domain',domain,contentId,locale,path,alternates}` in the existing route union.

`validate(records, context)` receives `{project,now,pages,recordIds}` (`recordIds` is `ReadonlySet<string>`). Keep callback validation free of I/O. The shared catalog also checks global IDs, locales, owned Page identity, reserved slugs, index-prefix ownership and public URL collisions. `richFields` declares native projection paths, including `*` array elements; detached validation returns the original editor values/ASTs.

```ts
import {getDomainRecords} from '../packages/content/domain-publication.mjs';
const rooms = getDomainRecords(content, 'rooms'); // readonly LocalizedRoom[]
```

Use a path relative to your consumer. Registered absent/disabled datasets return `[]`; unregistered runtime keys throw. `getDomainRouteRecord` provides minimal route presentation metadata for generic dispatch. `readContent(root,project,{now?,registry?})`, `localizeContent(source,locale,project,registry?)`, `validateCatalog(source,project,registry?)` and the keyed accessor accept registry injection only for isolated tests; production uses static registrations.

Set `enquiry:true` to contribute publicly eligible records to `getEnquiryContexts(content): {id,kind,title,path}[]`; offerings retain kind `offering`, extensions use their key. `getAcceptedEnquiryContexts(contents): {id,kind}[]` deduplicates the configured-locale union. `createManifest` exposes that union as `enquiryContexts` while retaining legacy arrays. The form uses localized options and its existing `contextId` query; the Worker validates the bounded scalar against the union. No client locale authority, new D1 schema or per-domain Worker branch is needed.

## Proof and lifecycle

`tests/domain-projection.test.ts` registers test-only workshops through public APIs, augments keyed maps, and proves clock/index publication, no fallback, alternatives, collisions and typed access. `tests/domain-extension.test.ts` plus `tests/fixtures/content/domain.ts` exercise lesson template/section/native aliases, dormant copy and owned identity; `tests/domain-native.test.ts` and `apps/site/tests/domain-rendering.test.ts` cover static adapters. These fixtures do not ship another production module. Rooms shows the complete real integration.

The initial framework was accepted in Task 2. Task 3 needed two controller-approved generic corrections: move renderer coverage to `getStaticPaths` to avoid an actual Astro import cycle, and initialize translated section drafts from registered `defaultCopy`/`richFields`. Both were reviewed with regressions. Future modules should use the resulting seams; this history is not a claim of zero generic edits after Task 2. The [chronological ruling ledger](superpowers/reviews/2026-10-18-composition-c/RULINGS.md) preserves the costs.

Stop the exact owned launcher before changing module flags, running conflicting configure/build/full tests, or rebuilding CMS. Edit `project.json`, run `pnpm configure`, then restart the owned `pnpm dev:cms` stack so collections/indexing and schema agree. Ordinary validated copy saves use the content watcher; static publication still needs a new build. Disabled domain folders and declared owned Page files are excluded before parsing; unknown navigation IDs still reject, while known dormant destinations may remain stored and hidden. Toggle flags without deleting dormant bytes.

Create flat drafts, choose stable filename/contentId/slug before first Save, explicitly initialize EN/EL copy and publish each locale's index and record. URLs stay immutable; redirects and relationship-aware deletion are outside this increment. Original local PNG/JPEG/WebP sources are bounded at 20 MiB, 20,000 pixels per side and 40 million pixels. Metadata checks are not exhaustive payload verification or a loading budget. Original files are served directly with intrinsic dimensions/lazy loading/crop classes; no optimized derivatives/srcsets exist. Choose suitably small media. See the Rooms guide for item/text bounds and native recovery.
